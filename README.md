# 2FAS Resources

This repository contains public, reusable resources from the 2FAS team.

It is a companion repo for tutorials, YouTube videos, and support content: command snippets, example configuration files, and small "copy-paste" helpers.

## What you will find here

- Example configs (safe defaults, placeholders)
- Command snippets used in videos
- Step-by-step helper files (Markdown)
- Small scripts or templates that make setups easier

## What you will NOT find here

- Application source code (see our other repositories)
- Secrets, tokens, private keys, passwords, or real credentials
- Anything that requires trusting a third-party service by default

## Safety and privacy notes

- Files in this repo may include example usernames, hosts, or paths. Always replace them with your own values.
- Never paste secrets into GitHub issues, YouTube comments, or Discord screenshots.
- If a guide asks for credentials, use app passwords or scoped credentials where possible.

## Structure

We keep content grouped by product and topic, so links stay stable across videos.

Suggested layout:

- `pass/`
  - `webdav/`
  - `sync/`
  - `recovery/`
- `auth/`
  - `backups/`
  - `desktop/`
- `common/`
  - `security-basics/`
